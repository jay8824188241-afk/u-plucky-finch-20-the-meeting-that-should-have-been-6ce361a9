A deterministic Node program that writes the email this meeting should have been: the decision, the reasons, and who does what, so a 30-minute sync becomes a two-minute read. It writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR`, then reads it back and verifies its format.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
